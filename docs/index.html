Windows x64 · 포터블 ZIP · 업데이트는 사용자 승인 후 설치

문서와 사진, 함께

PDF · HWP/HWPX · DOCX · PNG/JPG/JPEG/BMP 파일을 드래그해서 추가하세요.

필요한 만큼 출력

PDF와 DOCX 페이지를 지정하고, 완료한 파일도 프린터를 바꿔 다시 인쇄하세요.

다음 업데이트도 간단히

앱에서 버전을 확인하고 새 파일을 검증한 뒤 설치합니다. 설정과 인쇄 목록은 보존합니다.

처음 실행하기

  1. 다운로드 페이지에서 EasyPrint-버전-windows-x64.zip을 선택하세요.
  2. EasyPrint 폴더 전체를 쓰기 가능한 폴더에 압축 해제하세요.
  3. EasyPrint.exe를 실행하고 파일·프린터·페이지 범위를 확인한 뒤 인쇄하세요.

이후에는 앱 상단 업데이트 버튼을 사용하세요. 예전 버전에 버튼이 없다면 이번 버전을 한 번 직접 내려받아야 합니다.

알아두세요

DOCX에는 데스크톱 Microsoft Word, HWP/HWPX에는 한컴오피스 한/글이 필요합니다. 해당 오피스는 배포 파일에 포함되어 있지 않습니다. 한글 문서는 전체 인쇄만 지원합니다.

업데이트 확인은 GitHub로만 연결되며 문서나 개인 설정을 업로드하지 않습니다. 인쇄·예약 중에는 업데이트를 설치하지 않습니다. 코드 서명은 되어 있지 않으므로 공식 저장소와 파일 출처를 확인하세요.
