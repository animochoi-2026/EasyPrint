# PDF print engine

SumatraPDF.exe is the unmodified official SumatraPDF 3.6.1 x64 portable executable.
It is included to make release builds independent of upstream download availability.

- Corresponding source and build instructions: https://github.com/sumatrapdfreader/sumatrapdf/tree/3.6.1rel
- Official download: https://www.sumatrapdfreader.org/download-free-pdf-viewer

The build script checks the pinned executable hash before use. Do not commit personal SumatraPDF settings.
