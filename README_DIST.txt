Easy Print — 문서·사진 배치 인쇄 프로그램 (GitHub 업데이트 지원)
==========================================

■ 설치 방법
압축을 해제한 뒤 이 폴더(EasyPrint 폴더) 전체를 원하는 위치에 옮겨두고,
EasyPrint.exe를 더블클릭하면 바로 실행됩니다. 별도 설치 과정은 없습니다.

■ HWP(한글 문서) 인쇄 안내
HWP/HWPX 파일을 인쇄하려면 이 PC에 한컴오피스(한/글)가 설치되어 있어야 합니다.
PDF만 사용하신다면 한컴오피스 없이도 정상적으로 인쇄됩니다.

■ 지원 형식
PDF, HWP/HWPX, PNG/JPG/JPEG/BMP, DOCX를 지원합니다.
사진은 방향 정보를 반영하고 투명 배경을 흰색으로 처리하여 A4 한 장에 맞춥니다.
DOCX는 설치된 데스크톱 Microsoft Word로 직접 인쇄합니다. PDF로 변환하지 않습니다.
페이지 범위(예: 2-4,7)와 매수 및 선택한 프린터를 Word에 전달합니다.
페이지는 문서 처음부터 센 실제 순서입니다. 구역별 쪽 번호는 자동으로 대응시킵니다.
범위를 정확히 확인할 수 없는 문서는 전체 인쇄로 바꾸지 않고 오류로 중단합니다.
DOCX가 포함된 작업은 시작 전에 Word 실행 가능 여부를 확인합니다.
Word가 없거나 실행할 수 없으면 안내 팝업을 띄우고 이번 인쇄 작업 전체를 중지합니다.
남은 파일은 목록에 정지 상태로 유지되며, Word 확인 후 다시 시작할 수 있습니다.
Word 설치/인증/최초 실행이 필요하며, 웹 버전 Office만으로는 인쇄할 수 없습니다.
HWP/HWPX는 기존 한글 인쇄 관리자 방식으로 전체 페이지만 인쇄합니다.
지원 문서라도 암호/보안 정책 또는 문서 자체의 문제로 인쇄할 수 없을 수 있습니다.

■ 목록과 재인쇄
PDF는 추가 직후 백그라운드에서 전체 페이지 수를 조회하여 파일명 아래 표시합니다.
파일이 많거나 NAS가 느리면 잠시 '페이지 수 확인 중'이 표시될 수 있습니다.
완료 파일은 자동 삭제하지 않습니다. '완료·실패 정리'로 목록에서 제거할 수 있습니다.
프린터를 선택한 뒤 목록에서 파일을 선택하고 '선택 파일 재인쇄' 또는
'여기부터 재인쇄'를 누르세요. 후자는 선택한 파일부터 목록 끝까지 인쇄합니다.
재인쇄할 파일과 프린터를 확인한 후 시작하며 앞쪽 파일은 그대로 유지합니다.
인쇄 중 프린터와 이번 작업의 매수/범위는 잠깁니다. 정지 후 변경할 수 있습니다.
인쇄 중 새로 추가한 파일은 다음 '대기 파일 인쇄' 때 처리합니다.
범위 예시는 1-3,5 입니다. 빈칸은 전체이며, 잘못된 범위는 인쇄를 차단합니다.
PDF/한글/Word 인쇄는 시간 경과만으로 자동 중단하지 않습니다.

■ 탐색기 우클릭
앱 오른쪽 '우클릭 메뉴 등록'을 한 번 누르면 지원 파일에
'EasyPrint로 인쇄…' 메뉴가 추가됩니다. 관리자 권한은 필요하지 않습니다.
우클릭하면 파일을 EasyPrint 목록에 추가하며, 프린터와 범위를 확인한 뒤 인쇄하세요.
여러 파일을 열어도 같은 프로그램 폴더의 실행 중인 창으로 모입니다.
우클릭 다중 선택은 Windows의 Document 메뉴 모델(최대 15개)을 사용합니다.
더 많은 파일은 드래그하거나 '파일 추가'로 넣어주세요.
Windows 11에서는 '더 많은 옵션 표시' 안에 보일 수 있습니다.
'등록 해제'로 이 메뉴만 제거할 수 있으며, 기본 연결 프로그램은 바꾸지 않습니다.
앱 폴더를 옮기거나 새 버전 폴더로 교체하면 새 위치에서 다시 등록해주세요.

■ 변환/네트워크 파일
PDF와 한글 및 사진/DOCX는 로컬 임시 파일을 이용하며 정상 처리 후 정리합니다.
빠른인쇄용 PDF 캐시 기능은 유지됩니다. 원본과 같은 폴더의 캐시를 재사용합니다.
쓰기 권한이 없는 NAS에서도 원본을 읽을 수 있으면 인쇄를 시도합니다.
원본 문서는 수정하지 않습니다.

■ 처음 실행할 때
Windows Defender SmartScreen이 "알 수 없는 게시자" 경고를 띄울 수 있습니다.
이는 서명되지 않은 개인 배포 프로그램이라 뜨는 정상적인 경고입니다.
"추가 정보" 클릭 → "실행" 버튼을 눌러 진행하시면 됩니다.

일부 백신 프로그램이 이런 방식으로 만든 실행 파일을 오탐지하는 경우가 있습니다.
실행이 안 되거나 파일이 삭제된다면 백신의 예외(허용) 목록에 EasyPrint 폴더를
추가해주세요.

■ 문제가 생겼을 때
프로그램 폴더 안에 다음 파일들이 남는데, 문제 파악에 도움이 됩니다.
  - print.log   : 인쇄 시작/성공/실패 이력
  - crash.log   : 프로그램이 시작 중 오류로 꺼졌을 때의 상세 내용

■ 업데이트
공식 배포: https://github.com/animochoi-2026/EasyPrint/releases/latest
앱 상단 '업데이트' 버튼에서 확인하고, 승인하면 검증 후 설치·재시작합니다.
시작할 때도 새 버전을 확인하며, 인터넷 장애가 인쇄를 막지는 않습니다.
인쇄/예약 중에는 설치할 수 없습니다. 설정과 목록은 유지하며 자동 재인쇄는 하지 않습니다.
이전 프로그램 파일은 .easyprint_update_.../backup 폴더에 보관합니다.
예전 버전에 업데이트 버튼이 없다면 이번 ZIP을 한 번 직접 내려받아야 합니다.
프로그램 파일의 라이선스 및 의존성 소스는 LICENSE.txt/THIRD_PARTY_NOTICES.txt를 확인하세요.
